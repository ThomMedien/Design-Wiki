Coding and Design Overview

Coding translates visual concepts into functional products. For designers, it is about understanding the medium to ensure technical feasibility and better developer handoff.

The Core Web Trio

1. HTML: The structure and content (the skeleton).
    
2. CSS: The visual style and layout (the interior design).
    
3. JavaScript: The behavior and interactivity (the electricity).
    

Key Languages

- Swift/Kotlin: Native mobile apps.
    
- Python: Data and AI.
    
- SQL: Database management.
    

The IDE (Integrated Development Environment) An IDE is a workspace that combines a code editor with tools to build, test, and fix errors. It manages technical overhead and provides real time feedback. For designers, it helps manage design tokens like colors and fonts across large projects.

VS Code vs. Cursor

- VS Code: A highly customizable editor that uses extensions to add features. It is the industry standard for general coding.
    
- Cursor: An AI native editor. Unlike VS Code, the AI is built into its core, allowing it to understand entire projects and generate code from visual screenshots.
